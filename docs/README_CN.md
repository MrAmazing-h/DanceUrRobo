# DanceUrRobo

把人体动作转换成可回放、可检查的机器人舞蹈。首页只用一个同屏展示：人体参考骨架、带重力的 G1 全身舞蹈、DexMate 正面及侧面运动学回放。按同一参考时间原速对齐，详见[对照视频说明](SHOWCASE.md)。

目前保留两条独立路线：

- **G1 + Inspire 五指手**：使用预训练 GEAR-SONIC 控制全身，重力开启，底盘没有强制跟随；手指目标保持中性姿态，没有重新训练 RL。
- **DexMate Vega-1P/F5D6**：原有逆运动学与轨迹优化，零重力运动学回放。旧代码、数据和 v0.1.0 发布保留。

G1 原速 24 秒、半速 44 秒的记录均完成了有限的平衡检查，但仍有手部自碰撞、小幅关节超限和动作跟踪误差。不能据此称为“无碰撞”或“真机部署已验证”。

安装与运行见[首页](../README.md)，算法、模型来源、关节顺序和时间约定见 [G1 文档](G1.md)，具体结果见[评估说明](RESULTS.md)。公开模型通过固定版本和 SHA-256 下载，不依赖原服务器私人目录。

发布包提供同名视频与完整运动 NPZ，供离线检查；不含真机控制接口、模型权重、人体原视频或配乐。
